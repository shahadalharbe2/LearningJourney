# 📚 LearningJourney
### Small Steps. Lasting Progress.

**LearningJourney** is an iOS application designed to help users build consistent learning habits, track their daily progress, and stay motivated throughout their learning journey.

By combining personalized learning goals, daily streaks, and flexible freeze days, LearningJourney encourages users to make learning a sustainable part of their everyday lives.

---

## ✨ Key Features

### 🎯 Personalized Learning Goals
- Set a daily learning goal.
- Choose a learning duration.
- Update goals when learning priorities change.
- Confirm goal changes that reset the current streak.

### 🔥 Daily Learning Streaks
- Mark a day as **Learn** after completing a learning session.
- Track learning consistency through daily activity.
- Monitor progress toward personal learning goals.

### ❄️ Freeze Days
- Use the **Freeze** feature when taking a break from learning.
- Maintain learning consistency without requiring daily activity.
- Track frozen days separately from completed learning days.

### 📅 Learning Activity Calendar
- Explore learning history through a monthly calendar.
- Identify completed learning days highlighted in orange.
- Recognize frozen days highlighted in cyan.
- Review previous activity in a simple, read-only calendar.

### 📊 Activity Dashboard
- View learning and freeze counters.
- Navigate a weekly activity overview.
- Access the Learn and Freeze actions from one screen.
- See available and disabled actions based on the current activity state.

### 💾 Persistent Learning Data
- Save learning goals and activity records locally.
- Preserve learning progress between app launches.
- Continue the learning journey without repeatedly setting up a goal.

## 🏗️ App Architecture

LearningJourney follows the **Model–View–ViewModel (MVVM)** architectural pattern to keep the code organized, maintainable, and scalable.

- **Model:** Represents learning goals and daily activity records.
- **View:** Displays the user interface using SwiftUI.
- **ViewModel:** Manages application state and learning-related logic.

This structure separates the user interface from the application's business logic.

## 🎨 Design Philosophy

**Consistency over perfection.**

LearningJourney is built around the idea that meaningful progress comes from small, repeated actions.

Its interface uses a dark visual theme with distinctive activity colors:

- 🟠 **Orange:** Completed learning days.
- 🔵 **Cyan:** Freeze days.
- ⚫ **Dark interface:** A focused and minimal learning experience.

The design aims to make learning progress easy to understand and rewarding to maintain.
